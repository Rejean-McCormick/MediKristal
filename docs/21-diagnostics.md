# 21 — Taxonomie des actes diagnostiques

## Catalogue hiérarchique

Ce catalogue couvre les familles à prévoir ; il n'est pas une nomenclature officielle exhaustive de codes. Chaque acte réel doit référencer les codes/protocoles autorisés et être décliné par anatomie, méthode, population et établissement. Un outil, un prélèvement et un résultat restent distincts.

## Fiche d'acte

Identité/codes ; acte prescriptible ou composant ; indication et exclusions ; population ; inputs ; outputs ; méthode ; anatomie ; échantillon/tube/volume/conservation ; préparation ; risques et contraindications sourcés ; dépendances de personnel/équipement/consommables ; durée par étape ; performance par contexte ; suivi ; documents explicatifs ; droits ; coût et disponibilité par site.

Un panel référence ses composants et les règles de groupage, plutôt que réinventer chaque composant. Un examen avec contraste et sans contraste a des exigences différentes. Un résultat de dépistage positif ne devient pas diagnostic confirmé. Les procédures principalement thérapeutiques avec composante diagnostique gardent cette distinction.

## Enrichissement progressif

Importer référentiels avec versions, cartographier les catalogues locaux, identifier les actes non mappés, réviser et publier. Ne pas annoncer « tous les examens possibles » sur la seule couverture de LOINC ou SNOMED. La capacité disponible est la combinaison d'un acte et d'un contexte opérationnel complet.
